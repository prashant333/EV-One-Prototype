# Intellicar One - Project guide.

1. What this project is

A product-strategy deliverable for Intellicar, an EV telematics company serving six customer segments: Battery OEMs, swapping stations (Battery Smart, PointO), financing/leasing companies, first/last-mile mobility (Bounce, Milo), B2B mobility, and vehicle OEMs (MG, Tata).

2. This is an assignemnt for Product Manager role at intellicar, hence focus on the outline and how various modules interacts. 
3. There will be no actual DB connected hence all the data will be representational and shall be stored at code level itself.

4. The PRD is given in PRD folder.
5. Design files provided in Design folder.

**Before taking any decision not specified in doc, ask for it**

# Output

A cliclable web based interactive prototype.
